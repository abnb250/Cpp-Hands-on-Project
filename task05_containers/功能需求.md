# Task05 功能需求清单：模板链表、栈、队列

## 一、总体要求

- [ ] 用 C++ 模板实现三个容器：`List<T>`、`Stack<T>`、`Queue<T>`
- [ ] 三者内部都使用**动态内存**（`new` / `delete`），不使用 `std::vector` 等现成容器代替
- [ ] 编译无警告；用 ASan / Valgrind 检查无泄漏、无重复释放
- [ ] 满足下列基本类型。

| 类型 | 示例 | 说明 |
|---|---|---|
| `int` | `List<int>` | 最基础，必测 |
| `double` | `Stack<double>` | 验证非整数类型 |
| `char` | `Queue<char>` | 验证小类型 |
| `bool` | `Stack<bool>` | 验证特殊小类型 |
| `std::string` | `List<std::string>` | **重点**：非平凡类型，有堆内存，验证深拷贝 |

---

## 二、`List<T>`（模板链表）

### 基本功能
- [ ] 默认构造：得到空链表
- [ ] `push_back(const T&)` / `push_front(const T&)`：尾部 / 头部插入
- [ ] `pop_back()` / `pop_front()`：删除尾 / 头元素
- [ ] `front()` / `back()`：返回首 / 尾元素的引用
- [ ] `empty()`、`size()`、`clear()`
- [ ] 析构函数：释放所有节点

### 拷贝控制（重点）
- [ ] 拷贝构造：**深拷贝**，每个节点都新建
- [ ] 拷贝赋值：深拷贝，能正确处理自赋值 `a = a`
- [ ] 移动构造：**接管**原链表节点，原链表置空
- [ ] 移动赋值：先释放自身资源，再接管，原链表置空
- [ ] 移动构造 / 移动赋值标 `noexcept`
- [ ] 拷贝或移动后，两个链表互不影响；析构不重复释放

---

## 三、`Stack<T>`（模板栈，基于动态数组）

### 基本功能
- [ ] 默认构造：空栈
- [ ] `push(const T&)`：入栈，容量不够时扩容（如 ×2）
- [ ] `pop()`：出栈
- [ ] `top()`：返回栈顶元素引用
- [ ] `empty()`、`size()`、`clear()`
- [ ] 析构函数：`delete[]` 内部数组

### 拷贝控制（重点）
- [ ] 拷贝构造：**深拷贝**数组内容
- [ ] 拷贝赋值：深拷贝，正确处理自赋值
- [ ] 移动构造：接管指针、容量、大小，原对象置空
- [ ] 移动赋值：先释放自身，再接管，原对象置空
- [ ] 移动构造 / 移动赋值标 `noexcept`
- [ ] 扩容逻辑正确，扩容后旧数据完整保留

---

## 四、`Queue<T>`（模板队列，基于动态数组或链表）

### 基本功能
- [ ] 默认构造：空队列
- [ ] `push(const T&)`：入队
- [ ] `pop()`：出队
- [ ] `front()` / `back()`：返回队首 / 队尾元素引用
- [ ] `empty()`、`size()`、`clear()`
- [ ] 析构函数：释放内部资源

### 拷贝控制（重点）
- [ ] 拷贝构造：**深拷贝**
- [ ] 拷贝赋值：深拷贝，正确处理自赋值
- [ ] 移动构造：接管资源，原对象置空
- [ ] 移动赋值：先释放自身，再接管，原对象置空
- [ ] 移动构造 / 移动赋值标 `noexcept`

---

## 五、异常与边界（简单即可）

- [ ] 对空容器调用 `pop` / `front` / `top` 等，抛出 `std::out_of_range`
- [ ] 空容器调用 `clear()`、析构、移动后析构都不崩溃
- [ ] `push` 扩容失败时，原数据不丢失（基本异常安全）

---

## 六、交付物

- [ ] `list.h`、`stack.h`、`queue.h`

## 七、不要求（保持简单）

- 不要求迭代器、`operator[]`、`insert` / `erase` 任意位置
- 不要求模板特化、完美转发、`initializer_list`
- 不要求线程安全
- 不要求与 STL 接口完全一致
- 不要求编写测试文件
