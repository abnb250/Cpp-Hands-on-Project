# 任务一功能要求：日期类或复数类

## 日期类功能要求

1. 提供构造函数，接收年、月、日，并提供合理默认值。
2. 构造后校验日期合法性；非法日期统一采用抛出异常、调整为合法日期或标记无效状态之一，并在文档中说明。
3. 提供闰年判断静态方法，规则为能被4整除但不能被100整除，或能被400整除。
4. 提供日期合法性判断方法，检查月份范围、日期范围、闰年二月天数和平年二月天数。
5. 提供年、月、日访问方法，均为 const 成员函数。
6. 提供加等天数，修改当前对象并返回自身引用。
7. 提供减等天数，修改当前对象并返回自身引用。
8. 提供加号运算符，返回新日期，不修改原对象。
9. 提供减号运算符，返回新日期，不修改原对象。
10. 提供两个日期相减，返回相差天数，并正确处理先后顺序和负数结果。
11. 日期加减必须正确处理跨月、跨年、闰年、月末和年末。
12. 提供规范化方法或等价内部机制，把非法月、日调整为合法范围。
13. 提供前置自增、前置自减，返回自身引用；自增表示加一天，自减表示减一天。
14. 提供后置自增、后置自减，接收占位参数，返回旧值，不得返回引用。
15. 提供相等与不等运算符，基于日期内容比较，不比较对象地址。
16. 提供小于运算符，按年、月、日依次比较；其余比较运算符基于小于和等于组合实现或保持语义一致。
17. 所有比较运算符不得修改操作数。
18. 提供格式化输出方法，返回日期字符串表示，格式统一并补零。
19. 提供输出运算符，支持连续输出；输出空对象或无效对象不得崩溃，行为需明确。
20. 提供星期计算方法，为 const 方法，结果正确。

## 复数类功能要求

1. 提供构造函数，接收实部和虚部，默认表示零复数。
2. 提供实部和虚部访问方法，均为 const 成员函数。
3. 提供设置实部和虚部的方法，返回自身引用或 void，行为统一并文档说明。
4. 提供两个复数的加法、减法、乘法、除法，二元运算符不得修改操作数。
5. 复数除法按复数除法公式实现，并处理分母为零的情况。
6. 提供加等、减等、乘等、除等运算符，原地修改当前对象并返回自身引用。
7. 提供共轭方法，返回新对象，不修改原对象，实部不变、虚部取反。
8. 提供模方法，返回实部平方加虚部平方的平方根，为 const 方法。
9. 提供相等与不等运算符；浮点数比较明确采用允许误差或精确比较，若采用允许误差需定义误差常量并文档说明。
10. 提供实数左加复数，返回新的复数对象，通过非成员函数或友元实现以支持左操作数为实数。
11. 提供输出运算符，格式明确，如“实部+虚部i”，并处理虚部为负、虚部为零、实部为零等情况，格式统一美观，支持连续输出。
12. 提供输入运算符，明确输入格式；读取失败时保持流状态正确，对象仍可安全使用或状态明确。

## 公共功能与接口要求

1. 所有不修改对象的成员函数必须标记为 const。
2. 复合赋值运算符必须返回自身引用。
3. 二元运算符必须返回新对象，不得修改操作数。
4. 前置自增自减返回引用，后置自增自减返回旧值。
5. 流输出运算符必须支持连续输出。
6. 流输入运算符必须处理失败状态并保持流状态可控。
7. 友元或非成员函数的使用必须有必要理由，并在 README 中说明。
8. 公开接口保持封装性，不暴露不必要的内部实现细节。
9. 所有异常类型和信息必须清晰、统一。
10. 所有边界行为必须在 README 中说明。
11. 不得出现未定义行为，不得因非法输入直接崩溃。
