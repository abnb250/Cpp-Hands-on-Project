# C++核心能力闯关计划 README

## 项目简介

本项目基于《C++ Primer Plus》实战任务，围绕类设计、运算符重载、继承多态、STL、文件IO、异常处理、模板、RAII、移动语义和数据结构，提供一条从简到难的C++综合训练路径。

## 项目目标

- 每个任务独立实现，不直接复制现成代码。
- 编译无警告，内存检查无泄漏、无重复释放。
- 能编写测试用例，覆盖正常、边界和异常情况。
- 能解释设计原因，而不仅是“能跑”。
- 每个任务包含源代码、README、构建文件和测试记录。

## 任务难度排序

| 顺序 | 任务 | 难度 | 主要训练点 |
|---|---|---|---|
| 1 | 任务1：日期类或复数类 | 入门 | 运算符重载、封装、const、边界校验 |
| 2 | 任务2：学生成绩管理系统 | 入门到中等 | STL、文件IO、排序统计 |
| 3 | 任务3：图形计算器 | 中等 | 抽象基类、多态、虚析构、智能指针 |
| 4 | 任务4：图书管理系统OO版 | 中等偏上 | 继承、多态、STL、文件持久化、异常 |
| 5 | 任务5：模板链表、栈、队列 | 高 | 模板、指针、动态内存、深拷贝、移动语义 |
| 6 | 任务6：手写MyString | 高 | RAII、拷贝控制、移动语义、异常安全 |
| 7 | 任务7：手写MyVector模板 | 高到难 | 模板、动态数组、迭代器、完美转发、扩容安全 |
| 8 | 任务8：二叉搜索树 | 难 | 递归、树结构、删除策略、遍历、模板 |
