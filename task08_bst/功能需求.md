# 任务8：二叉搜索树——按编码顺序整理的需求

## 定位
- 难度：难。
- 目标：综合训练递归、树结构、删除策略、遍历、模板。
- 原则：只实现 BST 的核心子集，重点在“递归 + 删除 + 遍历 + 所有权管理”。

## 第 1 步：定异常策略
- 优先使用标准库异常：std::out_of_range、std::invalid_argument、std::bad_alloc。
- 空树查找/删除/访问最值时抛 std::out_of_range。
- 非法参数抛 std::invalid_argument。
- 内存分配失败交给 new 抛 std::bad_alloc，不自己吞。
- 不要求派生自定义异常。

## 第 2 步：定节点结构
- 私有嵌套结构 Node：T value、Node* left、Node* right。
- Node 构造时初始化 value，left/right 为 nullptr。
- 节点只由 BST 内部管理，不对外暴露。

## 第 3 步：定成员变量
- 私有成员：Node* root_、std::size_t size_。
- root_ 为 nullptr 当且仅当 size_ == 0。
- 不存高度、不存父指针，除非你主动把它作为扩展点。

## 第 4 步：写析构与递归释放
- 析构函数必须递归释放所有节点，标记 noexcept。
- 写私有 clear(Node*) 递归函数：后序遍历释放左右子树，再 delete 当前节点。
- 析构后 root_ = nullptr、size_ = 0，再次析构不重复释放。

## 第 5 步：写插入
- insert(const T&) 和 insert(T&&)：按 BST 性质递归或迭代插入，重复值按你的策略处理（拒绝或允许）。
- 插入成功 size_ 递增。
- 插入失败（重复值且拒绝）时不改变树，返回 false 或抛异常二选一，语义要一致。
- 插入过程中抛异常（new 失败）时树保持原状。

## 第 6 步：写查找
- contains(const T&) 返回 bool，按 BST 性质递归或迭代查找。
- find(const T&) 返回 Node* 或 const Node*，找不到返回 nullptr。
- 空树查找返回 false / nullptr，不抛异常。

## 第 7 步：写最值
- minimum() / maximum() 返回最小/最大值，空树抛 std::out_of_range。
- 写私有 minNode(Node*) / maxNode(Node*) 递归或迭代找最左/最右节点。
- 最值查找是删除双孩子节点的依赖，必须先实现。

## 第 8 步：写删除（核心难点）
- erase(const T&) 按值删除，删除成功 size_ 递减，返回 bool。
- 必须处理三种情况：
  - 叶子节点：直接 delete，父指针置空。
  - 只有一个孩子：用孩子替代当前节点，delete 当前节点。
  - 两个孩子：用右子树最小值（或左子树最大值）替换当前值，再递归删除那个最值节点。
- 删除后整棵树仍满足 BST 性质。
- 删除不存在的值不改变树，返回 false。
- 写私有 eraseNode(Node*, const T&) 递归实现，返回新的子树根。
- 注意：双孩子删除时不要 delete 被替换的节点，只替换 value，再删除最值节点。

## 第 9 步：写遍历
- 中序遍历：升序输出，必须实现。
- 前序、后序：可选，但建议实现，训练递归顺序。
- 层序遍历：可选，用 std::queue<Node*> 实现。
- 提供接受回调的遍历接口，例如 template<class Fn> void inorder(Fn&& fn) const，避免把输出方式写死。
- 遍历不修改树，标记 const。

## 第 10 步：写统计接口
- size()、empty()、clear()，size/empty 标记 noexcept。
- height()：递归求树高，空树返回 0，叶子返回 1。
- clear()：释放所有节点，root_ = nullptr，size_ = 0。

## 第 11 步：写拷贝构造与拷贝赋值
- 拷贝构造：深拷贝整棵树，递归复制每个节点。
- 写私有 clone(Node*) 递归函数，返回新子树根。
- 拷贝赋值：Copy-and-Swap 惯用法，自赋值安全。
- 拷贝过程中抛异常时，已复制的节点必须释放，原对象保持不变。

## 第 12 步：写移动构造与移动赋值
- 移动构造：标记 noexcept，接管 root_ 和 size_，把 other 置为空树。
- 移动赋值：标记 noexcept，先释放自己，再接管，把 other 置空。
- 自移动安全。
- 移动后 other 处于有效空树状态，可安全析构、可重新插入。

## 第 13 步：写 swap
- 成员 swap 或 friend swap，交换 root_ 和 size_。
- 标记 noexcept，只交换两个成员，不分配、不抛异常。
- 拷贝赋值依赖它。

## 第 14 步：写模板约束与迭代器（可选）
- 要求 T 支持 operator< 和 operator==，用 static_assert 或编译错误自然暴露。
- 可选：实现一个中序迭代器，支持 *、++、==、!=，满足前向迭代器基本语义。
- 迭代器失效规则要明确：插入不失效（除非扩容不存在，BST 没有扩容），删除失效被删节点及其迭代器。

## 第 15 步：写测试
- 正常流程：插入、查找、删除、遍历、最值、高度、size。
- 删除三种情况各测一遍：叶子、单孩子、双孩子。
- 边界情况：空树、单节点、重复插入、删除不存在的值、删除根节点。
- 拷贝 / 移动 / 自赋值 / 自移动。
- 模板实例化：至少用 int 和 std::string 各测一遍。
- 异常情况：空树访问最值抛 out_of_range、拷贝过程中抛异常原树不变。
- 内存检查：ASan 下无泄漏、无重复释放、无悬空指针。
- 验证 BST 性质：遍历结果升序。
